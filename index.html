WHAT IT READS

Timed text, not video.

JSON3 stores captions in an events array. CueLift reads each event’s start time, duration, and text segments to make standard subtitle cues. Timing-only events are skipped.

BEFORE YOU IMPORT

Check the timing.

Automatic captions can include repeated fragments or unusual timing. Review the preview and your final video before publishing. This tool converts a JSON3 file you already have; it does not download captions from YouTube.

FORMAT GUIDE

What changes in the file?

JSON3 stores time in milliseconds. SRT writes start and end times as HH:MM:SS,mmm; VTT uses a period instead of a comma and starts with WEBVTT. The text stays in its original language.

{"events":[{
  "tStartMs":1000,
  "dDurationMs":2500,
  "segs":[{"utf8":"Hello world"}]

Quick answers

What is a JSON3 file?

JSON3 is a timed caption format used by YouTube. A usable file contains an events array with timed text segments.

Are my captions uploaded?

No. File reading and conversion happen in your browser. This site does not send caption contents to a server.

Why are some events missing?

JSON3 can contain timing markers with no visible text. CueLift skips those markers. It also skips invalid or empty cues.

Does SRT keep word-level timing or styling?

No. SRT has one time range and plain text for each cue. JSON3 word offsets and styling are not carried into the download.
